SpeakSeek 2.0

Video analysis RAG chatbot

Finds out who is speaking in a video, transcribes what each person said, lines everything up on one timeline, and lets you chat with the video. Ask a question about the conversation, or ask it to clip any moment on demand.

  • Face tracking
  • Active speaker detection
  • Per-person transcription
  • Master timeline JSON
  • Chat and clip UI

Chat mode answers from the timestamped transcript. Clip mode calls an ffmpeg tool to cut the requested segment and plays it inline. An automated FFMPEG and yt-dlp pipeline replaced manual video segmenting, cutting multi-week logging workflows down to a few hours.

Local Research Agent

Runs on your own machine

A research agent that runs on your own machine. It does multi-step web retrieval and dynamic scraping, digs through Reddit, and synthesizes a detailed product analysis that is saved locally. Pydantic schemas keep tool calls and outputs structured, and LangChain astream gives live token streaming with step-by-step reasoning. You prompt it from a plain notepad window with Ctrl+Enter, no heavy UI.

The repo includes real runs, such as a mouse comparison and keyboard research. Next on the roadmap: a FAISS store for larger context and a LangGraph version of the workflow.

  • Python
  • LangChain
  • Pydantic
  • LM Studio
  • ReAct agent
  • DuckDuckGo
